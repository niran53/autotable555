# ระบบจัดตารางสอนอัตโนมัติ

เว็บสำหรับนำเข้าข้อมูลครู ห้องเรียน รายวิชา กลุ่มเรียน และการมอบหมายสอน แล้วจัดตารางให้อัตโนมัติ
โดย **ครูไม่ซ้อนคาบ ห้องไม่ซ้อนกัน และกลุ่มเรียนไม่มีสองวิชาในเวลาเดียวกัน** พร้อมตรวจผลซ้ำจากตารางจริงทุกครั้ง

- หน้าเว็บ: HTML + CSS + JavaScript ล้วน แยกไฟล์ ไม่ต้อง build
- ฐานข้อมูล: Supabase (ถ้ายังไม่ตั้งค่า ระบบจะบันทึกไว้ในเบราว์เซอร์แทน)
- Deploy: Vercel (static site)

---

## ความสามารถ

| หัวข้อที่ตรวจ | สิ่งที่ระบบทำ |
|---|---|
| นำเข้าหลายรูปแบบ | CSV / TSV (UTF-8 หรือ TIS-620), Excel .xlsx (อ่านเองไม่พึ่งไลบรารี), .xls/.ods, JSON, PDF ที่มีข้อความ นำเข้าหลายไฟล์พร้อมกันได้ |
| สถานะ / ยกเลิก / ลองใหม่ | ทุกไฟล์แสดงสถานะ (รอคิว, กำลังอ่าน, กำลังแปลง, สำเร็จ, ผิดพลาด, ยกเลิก) มีปุ่มยกเลิกและลองใหม่รายไฟล์ |
| ตรวจข้อมูลผิด | รหัสซ้ำ, อ้างถึงห้อง/ครู/วิชา/กลุ่มที่ไม่มี (พร้อมแนะนำรหัสที่ใกล้เคียง), ตัวเลขผิด, คอลัมน์หาย, รูปแบบเวลาผิด, ห้องจุไม่พอ, ไม่มีห้องประเภทที่ต้องใช้, ภาระครูเกินเวลาที่ว่าง ฯลฯ ทุกข้อบอก **ตำแหน่ง (ไฟล์ › แผ่นงาน › แถว)** และ **วิธีแก้** |
| ข้อมูลหลายขนาด | ตาราง "เทียบกับไฟล์ต้นฉบับ" แสดงจำนวนแถวในไฟล์ / อ่านเข้าระบบ / ถูกต้อง ของทุกตาราง มีชุดทดสอบเล็ก กลาง ใหญ่ (540 รายการสอน 1,628 คาบ) |
| พรีวิวก่อนบันทึก | ดูข้อมูลทุกตาราง ค้นหาได้ แถวที่ผิดเป็นสีแดง กด "ไปที่แถว" จากรายการปัญหา แล้วจึงกด **ยืนยันข้อมูลนำเข้า** (ปุ่มกดไม่ได้ถ้ายังมีข้อผิดพลาด) |
| สถานะระหว่างคำนวณ | แถบความคืบหน้า, ขั้นตอนปัจจุบัน, รอบค้นหา, จำนวนช่วงสอนที่วางแล้ว, เวลาที่ใช้, บันทึกการทำงาน ปุ่ม **ยกเลิก** และ **เริ่มใหม่** คำนวณใน Web Worker หน้าเว็บไม่ค้าง |
| ผลลัพธ์และหลักฐาน | จำนวนคาบที่จัดได้เทียบกับที่ต้องจัด, ยอดคาบชน (ครู/ห้อง/กลุ่ม) ที่ **นับใหม่จากรายการคาบจริง** ไม่ใช่ค่าที่ตัวจัดตารางรายงาน มีปุ่ม "ตรวจซ้ำจากตาราง" |
| ตัวชี้วัด | อัตราการใช้ห้องรายห้อง, เวลาว่างคั่นระหว่างวิชารายกลุ่ม, ภาระสอนรายครู (รายวัน, เทียบภาระสูงสุด) |
| การใช้งาน | สลับมุมมอง กลุ่มเรียน / ครู / ห้อง, ค้นหาวิชา (ไฮไลต์และบอกว่าอยู่ตารางไหนบ้าง), รายการคาบค้นหาและเรียงได้, คลิกบัตรวิชาดูรายละเอียด |
| ส่งออก | CSV, Excel (.xlsx หลายแผ่นงาน: สรุป รายการคาบ ตารางรายกลุ่ม/ครู/ห้อง ภาระสอน การใช้ห้อง), JSON และ **หน้าพิมพ์ PDF** (A4 แนวนอน หนึ่งตารางต่อหน้า) — ส่งออกได้หลัง "ยืนยันผลตาราง" เท่านั้น |
| รอบรัน | ทุกการจัดตารางบันทึกเป็นรอบรัน (สถานะ เวลา ผล การยืนยัน) ลง Supabase ดูย้อนหลัง เปิดผลเดิม และพิมพ์ได้ที่หน้า "ประวัติรอบรัน" |

## ติดตั้งและ Deploy

### 1) Supabase
1. สมัคร/เข้าสู่ระบบที่ supabase.com แล้วกด **New project**
2. เมนู **SQL Editor › New query** วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมดแล้วกด **Run**
3. เมนู **Project Settings › API** (หรือ Data API / API Keys) คัดลอก
   - **Project URL** เช่น `https://abcd1234.supabase.co`
   - **anon public key** (ขึ้นต้น `eyJ...`) หรือ **publishable key** (`sb_publishable_...`)
4. เปิด `js/config.js` แล้วใส่ค่า

```js
window.TT_CONFIG = {
  SUPABASE_URL: 'https://abcd1234.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...'
};
```

> ห้ามใส่ **service_role** หรือ **secret key** ลงในไฟล์นี้ คีย์ anon/publishable ใช้ฝั่งเบราว์เซอร์ได้ตามการออกแบบของ Supabase
> นโยบายใน `schema.sql` เปิดให้ผู้ที่มีลิงก์เว็บอ่าน/เพิ่ม/แก้ไขได้ (ไม่มีสิทธิ์ลบ) เหมาะกับการสาธิตและใช้ภายใน ถ้าต้องการจำกัดผู้ใช้ ให้เพิ่มระบบล็อกอินแล้วเปลี่ยนเป็น `to authenticated`

### 2) GitHub
วิธีที่ง่ายที่สุด (ไม่ต้องใช้คำสั่ง): สร้าง repository ใหม่ › **Add file › Upload files** › ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้นไป › Commit

หรือใช้ git:
```bash
cd timetable
git init
git add .
git commit -m "ระบบจัดตารางสอนอัตโนมัติ"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
git push -u origin main
```

### 3) Vercel
1. เข้า vercel.com › **Add New › Project** › เลือก repository จาก GitHub
2. Framework Preset: **Other** — Build Command: เว้นว่าง — Output Directory: เว้นว่าง (ใช้โฟลเดอร์ราก)
3. กด **Deploy** เมื่อเสร็จจะได้ลิงก์ `https://<ชื่อ>.vercel.app`
4. ทุกครั้งที่ push ขึ้น GitHub ระบบจะ deploy ใหม่ให้อัตโนมัติ

### 4) ตรวจหลัง deploy
เปิดเว็บ › **ตั้งค่า** › กด **ทดสอบการเชื่อมต่อ** ต้องขึ้น "เชื่อมต่อ Supabase สำเร็จ" และมุมขวาบนแสดง "Supabase" สีเขียว

### ทดลองในเครื่อง
ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เพื่อให้ Web Worker ทำงาน) เช่น
```bash
python -m http.server 8000      # แล้วเปิด http://localhost:8000
# หรือ
npx serve .
```
ถ้าดับเบิลคลิกเปิด `index.html` ตรง ๆ ก็ใช้งานได้ แต่จะคำนวณในหน้าเว็บแทน Worker

## รูปแบบข้อมูลนำเข้า

ใช้ไฟล์เดียวหลายแผ่นงาน (Excel), ไฟล์ CSV ที่มีบรรทัดหัวข้อ `#ครู`, `#ห้องเรียน` …, JSON `{ "teachers": [...], ... }` หรือแยกเป็นหลายไฟล์ก็ได้
ระบบรู้จักตารางจากชื่อแผ่นงาน/ชื่อไฟล์ หรือจากหัวคอลัมน์ (ภาษาไทยหรืออังกฤษ)

| ตาราง | คอลัมน์ (* = ต้องมี) |
|---|---|
| ครู (teachers) | รหัสครู*, ชื่อ-สกุล*, ตำแหน่ง, แผนกวิชา, ภาระสอนสูงสุด (คาบ/สัปดาห์), เวลาไม่ว่าง เช่น `พฤ1-4; ศ` |
| ห้องเรียน (rooms) | รหัสห้อง*, ชื่อห้อง, ประเภทห้อง, ความจุ (คน)*, อาคาร |
| รายวิชา (subjects) | รหัสวิชา*, ชื่อวิชา*, ทฤษฎี (ท), ปฏิบัติ (ป), หน่วยกิต (น), ประเภทห้องที่ใช้ |
| กลุ่มเรียน (groups) | รหัสกลุ่ม*, ชื่อกลุ่มเรียน*, ระดับชั้น, จำนวนผู้เรียน*, แผนกวิชา |
| การมอบหมายสอน (assignments) | รหัสกลุ่ม*, รหัสวิชา*, รหัสครู* (สอนร่วมใช้ `T001\|T002`), คาบ/สัปดาห์ (ว่าง = ท+ป), ห้องที่กำหนด, แบ่งคาบ เช่น `2+3` |

ดาวน์โหลดแม่แบบได้จากหน้า "นำเข้าข้อมูล" หรือโฟลเดอร์ `samples/template.*`

PDF: ต้องเป็น PDF ที่มีข้อความ (ส่งออกจาก Word/Excel/เว็บ) ไม่ใช่ภาพสแกน แต่ละตารางมีบรรทัดชื่อตารางกำกับ (เช่น "ครู") หรือขึ้นต้นด้วยแถวหัวคอลัมน์ ดูตัวอย่าง `samples/small.pdf`

## วิธีจัดตาราง (โดยย่อ)

1. แปลงแต่ละรายการสอนเป็น "ช่วงสอน" ตามการแบ่งคาบ (เช่น 5 คาบ → 3+2) แล้วคำนวณช่วงเวลาที่วางได้ (ไม่ทับเวลาไม่ว่างของครู ช่วงกิจกรรม และไม่คร่อมพัก) และห้องที่ใช้ได้ (ประเภทตรง จุพอ)
2. วางช่วงสอนที่ยากที่สุดก่อน เลือกช่องที่ว่างจริงและค่าปรับต่ำสุด
3. ช่วงสอนที่วางไม่ได้ ใช้ Iterative Forward Search: เลือกช่องที่ชนน้อยที่สุด ถอนช่วงสอนที่ชนออกแล้ววางใหม่ จนครบ
4. ปรับปรุงคุณภาพด้วย Hill Climbing (ย้ายเฉพาะไปช่องว่างจริง) เพื่อลดเวลาว่างคั่น กระจายวิชาไม่ให้ซ้ำวัน ไม่ให้ครูสอนเกินวันละ 6 คาบ ใช้ห้องขนาดพอดี
5. ทำหลายรอบด้วย seed ต่างกัน เลือกผลที่ดีที่สุด แล้ว `metrics.js` ตรวจคาบชนซ้ำจากรายการคาบจริงอีกครั้ง

ผลทดสอบชุดใหญ่ (90 ครู 65 ห้อง 60 กลุ่ม 540 รายการสอน 1,628 คาบ): จัดครบทุกคาบ คาบชน 0 ใช้เวลาประมาณ 3 วินาที

## สคริปต์สาธิตสำหรับกรรมการ

1. **นำเข้า › ชุดที่มีข้อผิดพลาด › นำเข้า** › กด "ตรวจข้อมูลและดูพรีวิว" — เห็นข้อผิดพลาด 10 รายการ (รหัสครู/ห้องซ้ำ, อ้างถึงห้อง R999 ที่ไม่มี, ครู T099 ที่ไม่มี, ความจุ "สามสิบ", เวลาไม่ว่าง "จันทร์เช้า" …) แต่ละข้อมีวิธีแก้ ปุ่มยืนยันกดไม่ได้
2. กลับไปนำเข้า › ล้างรายการ › นำเข้า **ชุดเล็ก / กลาง / ใหญ่** (เลือก Excel, CSV หรือ JSON) — ตาราง "เทียบกับไฟล์ต้นฉบับ" แสดงจำนวนแถวตรงกัน
3. ตรวจพรีวิว › **ยืนยันข้อมูลนำเข้า**
4. **จัดตาราง** (ชุดใหญ่ เห็นความคืบหน้าชัด) › กด **ยกเลิก** › กด **เริ่มใหม่**
5. **ตารางผลลัพธ์** — ดูยอดคาบ/คาบชน, ตรวจซ้ำจากตาราง, สลับมุมมอง, ค้นหาวิชา, แท็บภาระสอน การใช้ห้อง เวลาว่างคั่น
6. **ยืนยันผลตาราง** › ส่งออก CSV / Excel / JSON › **หน้าพิมพ์ PDF** › พิมพ์หรือบันทึกเป็น PDF
7. **ประวัติรอบรัน** — เห็นรอบที่ยกเลิกและรอบที่สำเร็จ (บันทึกใน Supabase)
